2. 지금 못 고친 것 — 무엇이 필요한가

항목왜 지금 못 고치나필요한 것
환경이 없는 씬의 금속이 어두움버그가 아니라 설계 한계입니다. 환경이 없으면 금속은 균일한 ambientColor 만 반사합니다(물리적으로는 맞는 결과). 10-08 부터 내장 씬(데모·헬멧·Sponza)·새 씬·새 프로젝트는 ApplyDefaultEnvironment 로 기본 HDR 환경이 들어가고 옛 씬 파일도 변환돼 있어, 남은 경우는 environment 키가 없는 씬 파일(현재 UndoPrefabTest 의 Spawn.json·Tree.json 같은 프리팹용 씬)과 사용자가 환경을 비운 씬입니다. 로더는 키가 없으면 빈 값을 그대로 두어 ambientColor 폴백으로 갑니다.결정: ① 환경이 없는 씬에 엔진 기본 환경(Cubemap 샘플 세트)을 자동 적용 — 옛 씬의 모습이 바뀜 ② 셰이더에 하늘/땅 그라데이션 같은 절차적 환경 — 반사 계산이 모든 씬에 영향 ③ 지금처럼 두고 씬 쪽에서 환경을 지정. 어느 쪽이든 기존 씬 화면 비교가 필요합니다.
모델 루트 경로 미실행노드가 둘 이상인 모델을 빈 루트 아래 묶는 경로(EditorApp.cpp 의 Scene::AddModel 호출부)는 코드에 있지만 실행해 볼 모델이 저장소에 없습니다. 동봉 모델 DamagedHelmet.glb·Sponza.gltf 는 둘 다 노드가 1개입니다(Sponza 의 nodes 를 직접 세어 확인).다중 노드 glTF 한 개(라이선스가 자유로운 샘플, 예: 계층이 있는 간단한 장면). 불러온 뒤 --dump-objects=1 로 계층·위치를 보고, 단일 노드 모델과 같은 방식으로 놓였는지 스크린샷으로 확인.
셰이더 모델을 정하는 곳이 두 군데런타임 컴파일(GetTargetProfile)과 빌드(vcxproj 의 ShaderModel)가 다른 도구의 설정이라 코드만으로 한 곳으로 합칠 수 없습니다.결정: ① 현재 상태 유지(올릴 때 두 군데를 같이 바꾼다는 주석) ② 시작할 때 .cso 의 프로파일(리플렉션)과 런타임 프로파일을 대조해 어긋나면 경고하는 검사 추가. 셰이더 모델을 실제로 올리는 일(컴퓨트·SM 5.1 이상)이 생길 때 같이 하는 것이 효율적입니다(가이드 3장 참고).
비균등 스케일 부모의 분해 근사로컬 변환은 pre × S × R × T 이고 pre 는 모델 노드의 임의 행렬(전단 포함)을 분해하지 않고 보관하므로, 모델을 불러온 노드는 정확히 표현됩니다. 그러나 편집 경로(기즈모·재부모화·SetWorldRotation/SetWorldMatrix)는 Transform::SetLocalMatrix 의 XMMatrixDecompose 로 S·R·T 에 되돌려 저장하므로, 비균등 스케일 부모 아래 회전된 자식은 여전히 전단을 잃는 근사입니다. 오차를 경고하는 정도는 가능하지만 원인(편집 경로가 S·R·T 만 저장)은 그대로입니다.설계 결정: 로컬을 행렬로 저장하거나(Transform 구조 변경, 씬 파일 버전 상승, 기즈모·인스펙터 전반에 영향), 비균등 스케일 부모 아래 회전된 자식을 금지/경고. 영향 범위가 커서 필요가 생길 때 다룹니다.
IBL 맵은 미리 구운 것만스카이박스에서 조도·프리필터·BRDF LUT 를 만들려면 컴퓨트 파이프라인이 필요합니다.22.6 의 4번(컴퓨트·UAV) 뒤 엔진 안 IBL 생성. 같은 가이드 3·4장.
샘플 IBL 세트가 약 2배 밝게 구워짐(씬 IBL 세기 0.5)자산 문제입니다. 세트를 다시 굽거나 세기를 다시 정해야 합니다.외부 도구(예: cmgen 계열, 또는 4번 이후 엔진 생성)로 맵을 다시 만든 뒤 모든 씬의 iblIntensity 를 1.0 기준으로 재조정하고 화면을 비교. 4번이 끝나면 엔진 생성물을 기준으로 삼는 편이 낫습니다.
스카이박스 UI 화면 확인 / 자동 검증의 사각자동 검증이 실제 입력(클릭·드래그·단축키)을 주입하지 못합니다. 자동화 인자는 --undo·--redo·--gesture·--drop*·--pick·--set-position 등으로 늘었지만 모두 명령을 대신 부르는 방식이고, io.AddMousePosEvent 나 SendInput 으로 입력 이벤트를 넣는 코드는 없습니다.입력 주입 수단: Win32 SendInput 기반 스크립트, 또는 ImGui 입력 큐에 이벤트를 넣는 자동화 모드(io.AddMousePosEvent 등)를 실행 인자 재생에 추가. 그러면 슬라이더 드래그·Ctrl+Z·드롭을 자동으로 검증할 수 있습니다(Undo 의 "확인하지 못한 것"도 함께 풀림).
