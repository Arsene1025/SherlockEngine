OL_TestScene 렌더링 리포트

2026-11-15 · 맵 배치 7,065개짜리 OL_TestScene 이 에디터에서 7~9 FPS 로 느렸던 원인을 가르고, 계측(1번)과 Hierarchy 클리퍼(2번)를 넣은 뒤 Release 로 다시 잰 기록입니다.

측정: x64\Release\SherlockEditor.exe (이 작업 트리를 Release 로 빌드), D3D11, 자동화 창 1280x720(씬 뷰 649x251), 399·341·391 프레임째 Stats 패널 값. 표본이 적어 ±10% 정도의 흔들림이 있습니다. 아직 커밋하지 않은 작업 트리 기준입니다.

1. 결론

Release 에서는 그림자를 켜도 약 108~121 FPS, 끄면 154~176 FPS 입니다. 처음 보셨던 6.8~9 FPS 는 Debug 빌드 수치였습니다.
  • CPU 프레임(그림자 켬)은 8.6~9.7ms, GPU 프레임은 2.8~4.5ms 라 병목은 여전히 CPU 입니다. 드로우 콜 수(메인 7,579 + 그림자 27,875)가 많아도 GPU 는 여유가 있습니다.
  • CPU 에서 가장 큰 항목은 BuildDrawList(2.4~3.3ms), 그다음이 그림자 패스 드로우 제출(2.3~2.9ms)과 GUI(1.9~3.1ms)입니다.
  • 예전 Stats 의 culled 는 메인 패스가 아니라 그림자 컬링 수였습니다. 메인 패스 컬링은 동작하고 있었고 표시가 틀렸을 뿐입니다. 이번에 둘 다 따로 표시하게 했습니다.

3. 프레임 한 번의 흐름

  1. Update — 고정 스텝, 스크립트 (0.001ms)
  2. GUI — 에디터 패널 전체, Hierarchy 포함
  3. Renderer::Render
    1. Prepare — 조명, 그림자 뷰 계산, 환경, b0·b2 상수 업로드
    2. BuildDrawList — 오브젝트 7,065개의 월드·역행렬·경계 구 계산, 파이프라인·재질 조회, DrawItem 9,545개 정렬
    3. ShadowPass — 캐스케이드 4개 × 9,545개를 훑으며 절두체 밖은 건너뜀, 드로우마다 상수 버퍼 Map
    4. MainPass — 9,545개를 훑으며 절두체 밖은 건너뜀, 스카이박스
    5. Tonemap — 블러·블룸은 이 씬에서 꺼져 있음
  4. UIPass, Present

5. 수정 전과의 비교

수정 전 Release 수치는 같은 씬을 11/7 빌드(메인 패스 컬링이 없던 바이너리)로 잰 값입니다. 창 크기와 씬 뷰 크기(732x251 대 649x251)가 약간 달라 정확한 1:1 비교는 아닙니다.

이득을 항목별로 나눌 수는 없습니다. 이전 바이너리는 11/10 커밋(메인 패스 절두체 컬링)을 포함하지 않아, 개선은 컬링과 클리퍼, 그리고 그 사이 다른 커밋이 합쳐진 결과입니다. 클리퍼만의 효과는 GUI 구간(4.8ms → 1.9~3.1ms)으로 짐작할 수 있지만, 이 구간에는 다른 패널도 들어 있습니다.
Debug 빌드는 이번에 다시 재지 않았습니다. 처음 보신 6.8~9 FPS (CPU 128~143ms) 가 Debug 수치라는 판단은 Release 가 4~6배 빠르다는 사실에 근거한 추정입니다. Debug 에서는 BuildDrawList 처럼 반복이 많은 구간이 가장 크게 느려질 것으로 보입니다.

7. 측정의 한계

  • 표본은 조건당 2~3개이고 한 프레임 값입니다. FPS 는 평균이지만 구간 시간은 그 프레임 한 번의 값이라 ±10% 이상 흔들립니다.
  • GPU MainPass 는 그림자를 켰을 때(0.8~1.1ms)가 껐을 때(2.5~3.7ms)보다 짧게 나왔습니다. 원인은 확인하지 못했습니다. GPU 클럭 변화나 타임스탬프 구간 경계 영향일 수 있어, GPU 구간 값은 참고용으로만 보십시오.
  • 씬 뷰가 649x251 로 작아 픽셀 비용(MainPass GPU)은 실제 사용 크기(1292x626)보다 낮게 나옵니다.
  • 카메라는 씬 파일에 저장된 에디터 카메라 한 곳에서만 쟀습니다. 시점에 따라 컬링되는 수가 달라집니다.
  • 측정을 위해 x64\Release\imgui.ini 를 임시로 바꿨다가 원래대로 되돌렸고, 그림자 끔 측정용 씬 사본은 지웠습니다.
