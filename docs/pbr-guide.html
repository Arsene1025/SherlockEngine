1. 왜 PBR인가

옛 방식(Blinn-Phong)은 재질마다 "스페큘러 색"과 "shininess"를 손으로 맞췄습니다. 조명이 바뀌면 다시 맞춰야 했습니다.

항목 Blinn-Phong (이전) PBR (2026-10-08 이후)
재질 입력 기본색, 스페큘러 색, shininess 기본색, metallic, roughness
에너지 보존 ✗거친 면과 매끈한 면의 총 반사량이 다름 ✓반사된 몫을 확산에서 뺌
프레넬 (스치는 각의 반사) ✗없음 ✓Schlick 근사
금속 표현 ✗못 함 ✓F0 = 기본색, 확산 없음
환경 반사 ✗상수 주변광 ✓큐브맵 IBL
glTF 재질 !근사로 환산 ✓값을 그대로 옮김
B

2. 빛이 표면에서 하는 일

빛이 표면에 닿으면 두 갈래로 나뉩니다.

  • 반사(specular): 표면에서 바로 튕깁니다. 하이라이트와 거울 같은 상이 됩니다.
  • 확산(diffuse): 표면 속으로 들어갔다가 사방으로 나옵니다. 물체의 "색"으로 보입니다.

금속은 속으로 들어간 빛을 곧바로 흡수합니다. 그래서 금속에는 확산이 없고, 반사가 자기 색을 띱니다. 유전체(플라스틱, 나무, 돌)는 반사가 약하고 무채색이며, 확산이 대부분입니다.

3. 재질을 정하는 세 숫자

입력 뜻 엔진 기본값
baseColor 확산색 (금속이면 반사색) (1,1,1,1)
metallic 0 = 유전체, 1 = 금속 0
roughness 0 = 거울, 1 = 아주 거침 0.5
emissive 스스로 내는 빛 (조명과 무관) 0
AO 텍스처 환경광이 닿기 어려운 구석을 어둡게 강도 1

glTF 텍스처는 G 채널이 거칠기, B 채널이 금속성, AO는 R 채널입니다. 셰이더는 거칠기를 0.03 아래로 올리지 않습니다. 0이면 GGX 분포가 발산해 NaN이 생깁니다.

F0: 정면에서 본 반사율

F0는 표면을 수직으로 볼 때 반사되는 빛의 비율입니다.

유전체는 대부분 2~5%라서 4%로 고정합니다. 금속은 기본색이 곧 F0입니다. 금이 노란 반사를 내는 이유입니다.

4. 직접광: Cook-Torrance

조명 하나가 주는 빛은 다음과 같습니다.

먼저 네 벡터를 정합니다. 모두 표면의 점 P에서 바깥으로 나가는 단위 벡터입니다.

기호 뜻
N 표면 노멀 (노멀 매핑 이후)
L 표면에서 광원을 향하는 방향
V 표면에서 카메라를 향하는 방향
H normalize(L + V), 하프 벡터

함정: LightData::direction은 빛이 나아가는 방향입니다. 방향광의 L은 −direction입니다. 부호를 안 뒤집으면 밝은 면과 어두운 면이 뒤바뀝니다.

반사 BRDF = D · G · F / (4 · N·L · N·V)

미세면 이론은 표면을 아주 작은 거울 조각의 모임으로 봅니다. L을 V로 반사하는 조각은 노멀이 H인 조각뿐입니다. 세 항이 그 조각을 설명합니다.

항 질문 엔진의 식
D 분포 노멀이 H인 조각이 얼마나 많은가 GGX: α² / (π((N·H)²(α²−1)+1)²), α = roughness²
G 가림 그 조각이 이웃에 가려지지 않을 확률 Smith-Schlick: G₁(N·L)·G₁(N·V), k = (rough+1)²/8
F 프레넬 그 조각이 빛을 얼마나 반사하나 F0 + (1−F0)(1−V·H)⁵
  • 거칠수록 D가 넓고 낮아져 하이라이트가 퍼집니다.
  • 스치듯 볼수록 F가 1에 가까워집니다. 호수 표면이 멀리서 거울처럼 보이는 이유입니다.
  • 분모의 0 나눗셈은 EPSILON으로 막습니다.

확산 = kd · albedo / π

kd = (1 − F)(1 − metallic)입니다. 반사로 나간 몫(F)을 빼서 에너지를 보존하고, 금속은 확산을 0으로 만듭니다.

왜 π를 곱하나

엔진은 조명의 color × intensity를 "빛에 수직인 면이 받는 조도 E"로 봅니다. 이 관례에서는 BRDF에 π를 곱해야 합니다. 확산항은 albedo/π × π로 π가 사라집니다. 덕분에 확산 밝기가 Blinn-Phong 시절과 같아서, 기존 씬의 조명 값을 고치지 않았습니다.

감쇠와 스포트

  • 점광과 스포트광: (1 − d/range)² / (kc + kl·d + kq·d²). range에서 정확히 0이 됩니다.
  • 스포트: 축과 −L의 코사인으로 안쪽 콘 1, 바깥 콘 밖 0, 사이는 선형입니다.
  • 그림자 맵은 0번 방향광 하나에만 적용됩니다.

5. 환경광: split-sum IBL

하늘 전체에서 오는 빛은 반구 적분이라 픽셀마다 풀 수 없습니다. Karis(2013)의 split-sum은 적분을 둘로 쪼개 미리 구운 텍스처로 바꿉니다.

텍스처 내용 쓰임
t10 확산 조도 노멀 방향 반구의 코사인 가중 평균 kd · albedo · irradiance
t11 반사 프리필터 반사 방향을 GGX로 미리 흐린 큐브, 밉마다 거칠기가 다름 prefiltered
t12 BRDF LUT F0에 곱할 값 A와 더할 값 B의 2D 표 F0·A + B
  • 프레넬은 FresnelSchlickRoughness를 씁니다. 거칠수록 스치는 각의 반사 상한이 1 − rough로 내려갑니다.
  • LUT가 없으면 Karis의 모바일 근사식 EnvBRDFApprox가 대신합니다.
  • AO는 환경광에만 곱합니다. 직접광에는 곱하지 않습니다.
  • 환경광은 그림자의 영향을 받지 않습니다.

맵이 없을 때의 대체

슬롯 1순위 대체
t11 반사 specular 맵 스카이박스 밉 체인 → 검은 큐브
t10 조도 irradiance 맵 t11 큐브의 끝에서 두 번째 밉(2×2) → 검은 큐브
t12 LUT brdfLut 흰 2D + EnvBRDFApprox

셋 다 없으면 ambientColor 하나로 대신합니다. 유전체에서는 예전 주변광과 거의 같은 밝기입니다.

6. HDR과 톤매핑

IBL 큐브는 부동소수점이라 태양 픽셀이 300을 넘습니다. 엔진은 이를 R16G16B16A16_FLOAT(half float)로 읽습니다. 8비트로 읽으면 태양이 하얀 원판이 되고 금속 반사가 1에서 잘립니다.

화면은 [0, 1]만 표현하므로 마지막에 ApplyExposureToneMap을 부릅니다.

  1. environment.exposure를 곱합니다.
  2. toneMapping이 켜져 있으면 ACES 근사(Narkowicz 2016)로 [0, 1]에 누릅니다.

기본값은 노출 1, 톤매핑 끔입니다. 환경이 없는 옛 씬의 색을 지키기 위해서입니다.

알려진 한계: 아직 HDR 렌더 타깃이 없습니다. 톤매핑을 셰이더 끝에서 합니다. 후처리 단계에서 별도 패스로 옮길 계획입니다.

G

7. 픽셀 셰이더의 전체 순서

  • 색공간: 알베도는 sRGB로 읽어 샘플링 시 선형으로 바뀝니다. 금속성/거칠기, AO, 노멀 맵은 선형입니다. 조명 계산은 전부 선형 공간입니다.
  • 방어 코드: 모든 정규화는 SafeNormalize를 거칩니다. 분모와 range는 EPSILON 이상입니다.
