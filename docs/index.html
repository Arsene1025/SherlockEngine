개요overview/

프로젝트가 지금 어떻게 생겼고 어떻게 거기까지 왔는지.

  • 개요 · 문서와 소스 읽기 가이드어떤 문서를 어떤 순서로, 어떤 소스와 함께 읽을지.
  • 개요 · 렌더링 해부실행부터 화면 표시까지의 구조, RHI, 설계 결정, 질문과 답. 다른 문서가 가장 많이 인용하는 본문입니다.
  • 개요 · 용어집Win32·C++·그래픽스·GPU 컴퓨트 용어. 작업 중에 물어본 용어를 모읍니다.
  • 개요 · 단계별 구현 기록0단계부터 11-F단계까지의 설계 이유·함정·검증, 부록으로 알려진 한계.

  • 계획 · Gerstner 바다 구현 기록계획과 달라진 점(간격 곡선, 대역 제한), 프레임 흐름, 먼 바다 반짝임 원인 실험, 검증 숫자.
  • 계획 · 컬링 카메라 고정 계획캐스케이드 고정을 오브젝트·조명 컬링으로 넓혀 자유 시점에서 컬링 결과를 보는 디버그 기능 — 카메라 분리, 컬링된 조명 끄기, UI·오버레이 3단계.
  • 계획 · 게임 UI(캔버스) 구현 계획유니티 uGUI 식 런타임 UI — Canvas·RectTransform·Image·Text(한글)·Button·위젯·레이아웃·스크롤·내비게이션·Rect 툴·World Space 8단계. 구현 결과·검증 숫자는 10장, 테스트 씬은 UiShowcase.
  • 계획 · 오브젝트별 강조·디졸브 구현 기록Highlight 컴포넌트 — 색 섞기·발광 번쩍임·가장자리 빛을 b1 PerObject 로. Dissolve 컴포넌트 — 진행도는 b1, 노이즈는 재질 셋 t20(비면 builtin:noise), 그림자 알파 테스트 변형(컷아웃 그림자도 구멍). 계층 상속, 검증 숫자.
  • 계획 · 비 구현 기록차폐 맵(위에서 내려다본 직교 깊이, t24) 카메라·패스·읽기, 상태 없는 빗줄기, 젖음·웅덩이·물결·튐, b0 640 B·b8, 네 조합·회귀·GPU 시간 검증, 막힌 것.
  • 계획 · 비 구현 계획위에서 내려다본 차폐 맵 하나를 같이 쓰는 빗줄기(정점 셰이더가 위치를 계산하는 절차적 파티클)와 젖은 표면 — 차폐 맵·빗줄기, 젖음, 튐·물결(선택) 3단계와 부하 예상.

보고서report/

실측값과 전후 비교, 그 결과로 내린 결정. 이미 끝난 작업의 근거를 날짜·조건별로 찾아보는 문서.

  • 보고서 · OL_TestScene 렌더링 리포트맵 7,065개 씬의 프레임 분석, 계측·Hierarchy 클리퍼 추가, Release 실측.
  • 보고서 · 계측·Hierarchy 클리퍼 비포/애프터같은 Release 조건에서 적용 전후 비교: 78→112 FPS(그림자 켬), GUI 5.2→2.6ms.
  • 보고서 · 월드 행렬 계층 순회 비포/애프터BuildDrawList 의 월드 행렬 계산을 루트에서 내려가는 방식으로 바꾼 전후: 계층 7,000개 씬 루프 0.82→0.59ms, 결과 비트 동일.
  • 보고서 · GetWorldMatrix 를 거치지 않기로 한 결정결정 이유, 고려한 선택지 6가지, 7,000개 실측 근거, 잠재 위험 9건과 후속 작업.
