개요overview/

프로젝트가 지금 어떻게 생겼고 어떻게 거기까지 왔는지.

  • 개요 · 문서와 소스 읽기 가이드어떤 문서를 어떤 순서로, 어떤 소스와 함께 읽을지.
  • 개요 · 렌더링 해부실행부터 화면 표시까지의 구조, RHI, 설계 결정, 질문과 답. 다른 문서가 가장 많이 인용하는 본문입니다.
  • 개요 · 용어집Win32·C++·그래픽스·GPU 컴퓨트 용어. 작업 중에 물어본 용어를 모읍니다.
  • 개요 · 단계별 구현 기록0단계부터 11-F단계까지의 설계 이유·함정·검증, 부록으로 알려진 한계.

보고서report/

실측값과 전후 비교, 그 결과로 내린 결정. 이미 끝난 작업의 근거를 날짜·조건별로 찾아보는 문서.

  • 보고서 · OL_TestScene 렌더링 리포트맵 7,065개 씬의 프레임 분석, 계측·Hierarchy 클리퍼 추가, Release 실측.
  • 보고서 · 계측·Hierarchy 클리퍼 비포/애프터같은 Release 조건에서 적용 전후 비교: 78→112 FPS(그림자 켬), GUI 5.2→2.6ms.
  • 보고서 · 월드 행렬 계층 순회 비포/애프터BuildDrawList 의 월드 행렬 계산을 루트에서 내려가는 방식으로 바꾼 전후: 계층 7,000개 씬 루프 0.82→0.59ms, 결과 비트 동일.
  • 보고서 · GetWorldMatrix 를 거치지 않기로 한 결정결정 이유, 고려한 선택지 6가지, 7,000개 실측 근거, 잠재 위험 9건과 후속 작업.
